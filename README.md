# Твой торт

Маленькая 3D-открытка на день рождения. Она собирает свой торт: форма, бисквит, крем, глазурь, бордюр и декор. Потом загораются свечи «29», она пишет письмо в следующий год со своими целями и желаниями, письмо сгорает над свечами, она задувает свечи, летит конфетти и открывается открытка. Готовый торт вместе с её желаниями можно сохранить картинкой. Желания никуда не отправляются и остаются только на её телефоне.

Сделано на three.js и Vite, рассчитано на iPhone в портретной ориентации. Все модели и звуки генерируются в коде. Снаружи подгружаются только шрифты Google Fonts; без сети текст покажется системным шрифтом.

## Что править

Тексты, открытка, письмо в следующий год, подпись и палитры лежат в [src/config.js](src/config.js). Цвета интерфейса собраны в начале [src/style.css](src/style.css).

## Запуск

```bash
npm install
npm run dev
```

Vite печатает адрес в локальной сети, его можно открыть на телефоне в той же Wi-Fi-сети. Микрофон работает только по HTTPS, то есть уже на GitHub Pages; задуть свечи пальцем можно везде.

## Публикация

При пуше в `main` workflow [.github/workflows/pages.yml](.github/workflows/pages.yml) собирает сайт и выкладывает его на GitHub Pages. В настройках репозитория один раз нужно выбрать Settings → Pages → Source: GitHub Actions.
