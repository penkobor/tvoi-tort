# Твой торт

Маленькая 3D-игра на день рождения. Лошадь, похожая на Спирита, скачет по прерии под песню и ловит пожелания: силу, успех, здоровье, мечты, цели, счастье и любовь. В конце она сама прыгает через каньон к торту с «29». Гости держат торт, она задувает свечи, потом салют и короткое письмо.

Сделано на three.js без сборки: библиотека подгружается с jsdelivr через import map. Рассчитано на iPhone в портретной ориентации.

## Что править

Всё в [js/config.js](js/config.js): заголовок, текст письма, «Я тебя люблю», пожелания, песня и фото гостей.

- **Песня.** Если положить свой файл `assets/song.mp3` или `assets/song.m4a`, музыка включится с первого касания экрана, в том числе на iPhone. Без файла играет YouTube-плеер, и на iPhone нужно нажать ▶ в самом плеере.
- **Фото гостей.** PNG с прозрачным фоном в `assets/people/`. Фигура обрезается по непрозрачным пикселям сама.
- **Задуть по-настоящему.** Кнопка с микрофоном работает только по HTTPS, то есть на GitHub Pages. Пальцем свечи можно задуть везде.

Параметры для быстрого просмотра сцен: `?scene=approach` (прыжок), `?scene=cake`, `?scene=message`.

## Запуск

```bash
python3 -m http.server 8890
```

Потом открыть http://localhost:8890. С телефона в той же Wi-Fi-сети: `http://<IP компьютера>:8890`.

## Публикация

При пуше в `main` workflow [.github/workflows/pages.yml](.github/workflows/pages.yml) выкладывает файлы на GitHub Pages как есть, без сборки.
